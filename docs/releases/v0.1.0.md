# v0.1.0

`arev` brings the review workflow into one CLI. You can build a packet for a
Git change, run a reviewer, and check whether the recorded review passes
the gate for that exact head.

- Build review packets with merge-base rules and a content-bound packet ID.
  Record and resolve findings in an append-only ledger, gate the reviewed
  head, and exchange reports through import and export.
- Select a reviewer by pull request number and implementer identity. PR
  packets carry the PR description and referenced issue text as framed
  contract data.
- Run a reviewer against a detached checkout. Supported hosts submit one
  report over scoped MCP stdio, and the runner records it after checking
  that the checkout is clean. JSON output and brief import are available
  as fallbacks.
- Use `arev setup` to register the MCP server and install the review skill.

Install with `bun add -g @staix/agent-review` on Bun 1.4.4 or newer.
