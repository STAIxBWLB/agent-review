# v0.1.1

`arev run` can now record reviews with Codex, Claude and Kimi in the
real-host parity fixture.

- Codex can submit a report over MCP without an interactive approval.
  Approval is limited to the four tools of the run-scoped server.
- Claude runs in plan mode without user plugins and hooks. The checkout
  still has to pass the same clean-state check before a report is recorded.
- Kimi's JSON fallback prompt shows the exact report shape. The runner
  handles a bullet added before the opening JSON fence, and the report
  still passes the existing validator.

The real-host check recorded the same synthetic Git change through Codex
MCP and through Claude and Kimi's JSON output.

Update with `bun add -g @staix/agent-review@0.1.1`. Bun 1.4.4 or newer is required.
